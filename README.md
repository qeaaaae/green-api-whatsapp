# GREEN-API WhatsApp Chat

Браузерный клиент WhatsApp поверх [GREEN-API](https://green-api.com).
Одностраничное приложение без бэкенда: все запросы идут напрямую из
браузера в `api.green-api.com`, входящие приходят через очередь
уведомлений инстанса (long-polling). Сборка - статические файлы для
любого статического хостинга.

## Возможности

- Вход по `idInstance` / `apiTokenInstance` из личного кабинета
  GREEN-API, статус инстанса проверяется при входе
- Чаты аккаунта, последние сообщения и звонки подтягиваются
  автоматически при входе; новый чат - по номеру с маской ввода,
  готовому `chatId` или контакту из автодополнения телефонной книги
- Текст, файлы (загрузка и по ссылке), фото с камеры, контакты,
  геолокации, опросы
- Ответ с цитатой (клик - переход к оригиналу, в цитате 'Вы' или имя),
  пересылка, редактирование и удаление своих сообщений, реакции
- Кликабельные ссылки в тексте сообщений и подписях к файлам
- Статусы доставки, отметки прочтения, 'печатает...' собеседнику
- Диагностика инстанса: очереди исходящих/уведомлений, история
  состояний, перезапуск и разлогин
- История и сессия в localStorage, синхронизация между вкладками
- Светлая/тёмная тема, масштаб интерфейса, адаптивная вёрстка
- Устанавливается как приложение (PWA): 'Добавить на главный экран'
  на телефоне или кнопка установки в адресной строке Chrome на десктопе

Полная карта функционала: все фичи, методы GREEN-API и вебхуки - в
[FEATURES.md](FEATURES.md). Архитектура и ключевые решения - в
[SPEC.md](SPEC.md).

## Стек

React 19 · TypeScript · Vite · Zustand (persist) · Ant Design 6 ·
oxlint · Vitest

## Быстрый старт

Требования: Node.js 20+ и авторизованный инстанс GREEN-API. Авторизация -
в [console.green-api.com](https://console.green-api.com): сканируется
QR-код из WhatsApp.

```bash
npm install
npm run dev
```

Откройте http://localhost:5173 и введите `idInstance` и
`apiTokenInstance` из личного кабинета. Приложение проверит, что инстанс
в статусе `authorized`, включит приём уведомлений на инстансе и подтянет
чаты аккаунта. Если инстанс не авторизован - сначала отсканируйте QR в
личном кабинете.

## Тесты

```bash
npm run test
```

94 юнит-теста Vitest покрывают всю логику вне React: мапперы
уведомлений и журнала, цикл поллинга (ack, backoff, гарантированный
ack при ошибке диспетча), синхронизацию аккаунта, стор чатов (дедуп,
монотонные статусы, pending -> error при рестарте), нормализацию
номеров, линковку URL, поиск по контактам. Сторы и зависимости
инъектируются - реальные вызовы API в тестах не выполняются.

```
                         ensureReceivingSettings, ApiError, media-хост
  types.ts               Credentials, ChatMessage, Chat, типы тел
                         уведомлений
  lib/                   чистая логика без React (покрыта тестами):
    poller.ts              цикл receiveNotification/deleteNotification,
                           dispatchNotification, догрузка цитат
    sync.ts                первичная синхронизация аккаунта при входе
    notifications.ts       мапперы тел уведомлений -> ChatMessage,
                           статусы, реакции, звонки, сервисные события
    history.ts             getChatHistory -> догрузка истории чата,
                           маппер журнала toMessage
    chatTitle.ts           lazy-резолв имён и аватаров чатов
    contacts.ts            подписи и поиск по телефонной книге
    chatId.ts              нормализация номера -> chatId, маска ввода,
                           isSendableChatId
    format.ts              даты, время, длительность звонков, цвет аватара
    storage.ts             persist-хранилище с fallback в память
  store/                 Zustand-сторы с persist в localStorage:
    authStore.ts           креды инстанса + баннер ошибки связи
    chatStore.ts           чаты, сообщения, activeChatId, instanceId
    uiStore.ts             тема и масштаб интерфейса
  hooks/
    useNotifications.ts    запуск поллинга (Web Locks - поллит только
                           вкладка-лидер) + синк сторов между вкладками
  components/            LoginScreen, ChatList, ChatWindow,
                         MessageBubble, AttachmentMenu, ImageLightbox,
                         DiagnosticsModal
  components/attachments/  модалки вложений: файл, файл по ссылке,
                           контакт, локация, опрос
  App.tsx                композиция экранов, тема antd, вход/выход
  index.css              темы на CSS-переменных, скроллбары, пузыри,
                         узор чата
```

Тесты лежат рядом с кодом: `*.test.ts` в `src/lib` и `src/store`.

## Сборка и деплой

```bash
npm run build
```

Результат - статические файлы в `dist/`. Их можно раздавать любым
статическим хостингом (Vercel, Netlify, nginx, GitHub Pages и т.д.) -
бэкенд и переменные окружения не требуются.

Деплой на Vercel:

```bash
npm i -g vercel
vercel deploy --prod
```

Либо через веб-интерфейс: импортировать репозиторий, Vercel сам определит
Vite и выполнит `npm run build` с публикацией `dist/`.

Локальная проверка production-сборки:

```bash
npm run preview
```

## Как пользоваться

1. Авторизуйте инстанс в [личном кабинете GREEN-API](https://console.green-api.com).
2. На экране входа введите `idInstance` и `apiTokenInstance` -
   приложение проверит статус инстанса и включит приём входящих
   уведомлений.
3. Существующие чаты аккаунта подтянутся автоматически. Для нового
   начните вводить номер или имя - выпадет список контактов аккаунта -
   либо введите номер (например `79991234567`) и нажмите `+`. Номер
   нормализуется в `chatId` вида `79991234567@c.us`. Для группы можно
   ввести готовый `chatId` вида `...@g.us`.
4. Напишите сообщение - оно будет доставлено получателю в WhatsApp.
5. Ответ появится в чате автоматически.

## Ограничения

- Редактирование - только своих текстовых сообщений и в течение 15 минут
  после отправки (ограничение WhatsApp)
- На бесплатном тарифе GREEN-API действует месячная квота и ограниченный
  список номеров получателей - смотрите условия тарифа в личном кабинете
- `apiTokenInstance` передаётся в URL API - так устроен GREEN-API; для
  production-решения с жёсткими требованиями к безопасности понадобится
  прокси-бэкенд
